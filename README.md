# Protótipo do site CronoSESI, produzido para a matéria de Levantamento de requisitos do curso de desenvolvimento de sistemas

[Link para o site CronoSESI](https://leandroimenes.my.canva.site/cronosesi)

## Nossos objetivos
Com o CronoSESI, queremos facilitar a vida dos estudantes SESI, ao criar funcionalidades que garantem informações de suas escolas de modo rápido e simples de se acessar. Em nosso site, os estudantes podem acessar um calendário que os mostram as datas de trabalhos, tarefas, provas, olimpíadas, etc. Também, em uma das abas, é possível criar grupos de estudos sobre as matérias do seu ano escolar, escolhendo sua proficiência em cada matéria. Também temos um chat de suporte super qualificado, que responderá qualquer dúvida que tiver em relação ao site.
